# Mei 出貨整理 Excel

以 [合成範例活頁簿](assets/mei-shipping-example.xlsx) 為格式參考，另存當批 `.xlsx`。
使用者提供新版出貨範本時，以該範本為準。範例內的示例列必須替換。月份取自開團月份或使用者指定值，和發文或擷取日期分開。

## 分頁、欄位與公式

維持以下順序。前兩頁第 1 列放 `YYYY-MM` 和分頁名稱，說明放在表頭上方，第 4 列放表頭。買家分單從第 4 列開始逐位排列。

| 分頁 | 從左到右的欄位 |
| --- | --- |
| 出貨總表 | 買家名字、合併書單（匯出時）、總數量、總金額、筆數、網站訂單數、網站金額、記事本金額、電話、核對、包裹編號 |
| 包書明細 | 包裹編號、媽媽、開團／訂單、商品、定價、團價、數量、金額、包書確認 |
| 買家分單 | 買家名字、品項、定價、團價、數量、金額、包裹編號。每位買家的首列在 A 欄放暱稱、B:F 放表頭、G 欄顯示 `包裹 001`，其下列品項，末尾放品項小計與總結金額。 |

- **包書明細**是團價和數量的編輯入口。每買家每品項一列，買家之間留空列。H 欄用 `=F5*G5`。定價缺資料時留白。可包書的列使用 `□` 待勾，待核對列寫清楚原因。
- **出貨總表**每買家一列。合併書單是匯出當時的多行快照，格式為 `品項 ×2｜$300`。總數量加總本買家明細 G 欄，記事本金額只加總明細中來自記事本的品項。總金額等於網站金額加記事本金額。網站金額採網站訂單金額，可能與品項小計不同。純記事本輸出中，網站訂單數與網站金額填 0。表尾放總計，電話無可靠來源時留白。
- **買家分單**的品名、定價、團價、數量和金額連到包書明細，空白定價維持空白。品項小計加總本區塊的數量與金額，總結金額連到出貨總表。已標記待核對的買家或品項在分單也應能辨識。
- 保留範本的欄寬、文字與數字類型、買家區塊及前兩頁篩選。包裹編號從文字 `001` 起，三頁一致，僅供這份 Excel 使用。金額用數字儲存，版面以範例的簡潔表格為準。

## 整理與交付

1. 先核對來源貼文、留言筆數、商品與團價。保留逐則原文供追查。重新擷取時比較版本，同一份資料不要重複累加。版媽的總數通知用來對帳，避免再加成一筆訂單。
2. 在同一社群內，依已核對的顯示暱稱整理各買家的品項。比對網站買家或電話需有獨立資料。未具名代喊另列，候補、超量或未確認供貨在相關列標示。若將這些列放進核對版，表首及總結金額須標為需求試算，並在交付摘要分開報出正式喊單與候補數量。
3. 以新檔輸出三個分頁。檢查每位買家的品項、包裹編號及各表金額對得上。用副本修改一筆團價或數量，確認明細、總表與分單連動，存檔後重新開啟確認。交付新檔和簡短核對摘要。

把實際訂單、電話、原始範本與來源截圖留在 Git 忽略的本機目錄。若任務是網站匯入預覽，改按專案的 `docs/MEI_NOTEBOOK_IMPORT.md` 使用既有匯入格式。
